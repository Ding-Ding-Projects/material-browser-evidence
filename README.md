# Material Browser evidence

Browse the [reviewed interface gallery](https://ding-ding-projects.github.io/material-browser-evidence/) or read the [evidence method](https://ding-ding-projects.github.io/material-browser-evidence/evidence.html).

The gallery contains eight pixel-reviewed original captures from a closed runtime session, bound to source revision `baa9512ecbc2727929547059f3b5d95f7cde989f`. It uses synthetic data. The inventory records image, package, renderer and host hashes with UTC capture times.

The evidence reports runtime-forced scale and CSS viewport dimensions. Physical display scaling, native keyboard delivery, installer behavior and unlisted product states are not claimed.

## Build

Run `build.bat` to create the static site in `site/`. This static gallery has no installable application target; `build-installer.bat` exits with a non-success result by design.
