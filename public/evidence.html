How to read this evidence

This gallery contains ten inspected original PNGs of the WorldLens-style desktop renderer at source revision 284fc88f94487a7716099469daadeec258d97b07. The application used its real Electron main/preload and locally built Linux Rust host, with a task-owned Xvfb display and isolated synthetic vault. It was an unpackaged application run, not a Windows installer test.

Window, CSS viewport and interface zoom

Each card distinguishes captured image dimensions, the application window size, the measured CSS viewport and actual Electron zoom when the source inventory supplies them. A 760 × 580 window at 200% interface zoom does not have a 760 × 580 CSS viewport. Electron zoom changes the logical space available to the interface; device pixel ratio and physical monitor scaling are separate measurements. No physical display-scale change is claimed.

Review and operations

The original images were decoded, visually inspected and copied without changing their bytes. The real native host created synthetic profiles and saved template metadata. The launch consent review was opened and cancelled. Browser launch, guest provisioning, synchronization transfer and destructive confirmation behavior are not established by these screenshots.

Settings and sound limits

Language and theme variations used explicitly seeded startup preferences through the application's legacy presentation reader in the isolated profile. They do not establish successful native preference saving. The existing Windows mutex implementation rejects native preference persistence on Linux; the interface preserves the storage warning. No locking or persistence boundary was bypassed. Bundled Roboto was rendered independently of Windows installed-font enumeration. The sound controls and preview are visible, but screenshots and audio-graph checks do not prove audible speaker output. The floating Accessibility control overlaps content at some scroll positions; the tested Accent Reset action became pointer-reachable after scrolling.

Coverage

The representative Appearance matrix covers 1280 × 800 and 760 × 580 windows, English, Cantonese and bilingual text, light, dark and high contrast, and actual Electron zoom factors of 100%, 125%, 150% and 200%. Normal captures also cover the shell, all ten Settings categories, profiles, Super Profiles, synchronization, setup and review dialogs. The complete run reports 143 captures (137 main and six supplementary), 72 Appearance matrix tuples and 61 of 241 inventoried states exercised; 180 states remain unverified. Measured states, inspected images and blocked cases are recorded separately in the coverage record. These ten selected images do not represent every matrix cell or every design-inventory state.

Unverified by this gallery

  • Windows installation, updates and native preference persistence across restart.
  • Physical display scaling and native Windows keyboard delivery.
  • Screen-reader speech, audible speaker output and guest lifecycle acceptance.
  • Unlisted product states and operations.
