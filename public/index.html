Ten original captures show the WorldLens-style desktop workspace, profile and template inspectors, setup, synchronization, launch consent, sound controls, light and high-contrast appearance, and bilingual text at 200% interface zoom. Each image retains its source-bound provenance.

Window dimensions and CSS viewport are recorded separately. Windows installation, native preference persistence and physical sound output remain outside this evidence.

What this set covers

The original PNGs were decoded and visually inspected, then copied without modifying their bytes. Real native operations created synthetic profiles and saved template metadata; the launch review was opened and cancelled. These observations do not establish browser launch, guest provisioning or synchronization transfer. The visible storage warning records a Linux limitation of the existing Windows preference-locking implementation.
