Evidence guide

How to read this evidence

This gallery contains eight original PNG captures selected from a closed runtime session. Each card includes its capture time in UTC, source revision, image SHA-256, application package SHA-256, renderer SHA-256, and host SHA-256.

Viewport and scale

The listed width and height are CSS viewport pixels. The application runtime was instructed to use scale 1 for this selected set. That is useful viewport evidence, but it does not measure or establish the physical display scale on the host computer.

Review and privacy

Each selected original image was reviewed for legibility and privacy before publication. The selected records are synthetic. The gallery excludes 48 notification-obscured variants from an earlier 125% pass. The 150% run is closed and has 42 metadata-valid matrix cells, but those images were not individually reviewed for this gallery. No 200% run was started.

Limits

  • Native keyboard delivery was not verified.
  • Physical host display scaling was not changed or verified.
  • The set covers representative workflows rather than every state.
  • Installer behavior is outside this gallery's evidence.
